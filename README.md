# NOOR Original 500

Headless Shopify storefront — Next.js 16, Tailwind, Firebase, NOOR theme.

## Quick start

```bash
npm install
vercel env pull .env.local --environment=development --yes   # requires Vercel link
npm run dev
```

Open http://localhost:3000
